# 求职学习图鉴

中国大陆 AI／互联网技术岗位的技能图鉴与本地学习计划。React、TypeScript、Vinext、shadcn/ui、Lucide。

## 开发与构建

需要 Node.js 22.13 或以上。安装依赖后运行 `npm run dev`；`npm run build` 生成可部署的 Cloudflare Worker。`npx tsc --noEmit` 检查类型。`node --experimental-strip-types --test tests/core.test.mjs` 验证备份与证据处理。

## 当前可用

- 岗位搜索表单、城市和经验筛选、错误及取消状态。
- 明确标注的虚构演示图鉴、技能筛选排序、证据抽屉、多选加入计划。
- 多份本地计划、任务日期与状态、排序、笔记、自动保存、计划删除撤销。
- 单份／全部 JSON 备份、校验和预览后合并导入；不覆盖原计划。
- 服务端实时检索适配器：Tavily 搜索和正文、兼容 Chat Completions JSON 的模型服务。

## 配置真实检索

将 `.env.example` 复制为 `.dev.vars`，填写 `TAVILY_API_KEY`、`MODEL_API_KEY`、`MODEL_NAME`，按供应商需要设置完整的 `MODEL_API_URL`。默认地址是 DeepSeek Chat Completions；模型名称由维护者填写，不假设账号有某个模型权限。Sites 上通过运行时环境变量配置，不把密钥放进页面或 hosting.json。

**未配置密钥时，真实检索明确返回 503；不会自动切成演示或虚构招聘结果。** 供应商账户、数据许可和真实招聘可达性仍需实际验证。搜索服务费用由供应商账户承担。本项目不绕过来源登录、验证码或反爬机制。

只分析预设招聘平台及企业招聘域名的正文；有招聘正文不代表已获得自动采集授权，上线前维护者仍须核实来源条件。搜索服务不保证能读取所有来源。搜索索引可能过期，无法证明职位仍在招聘。

## 数据准确性

正文先按 URL 和内容去重；模型只提取单职位与岗位相关的要求。引用必须是正文连续文本（忽略空白和全半角），元数据也验证原文。公司、岗位、城市再次去重；每个技能按职位去重计数。筛选城市和经验没有正文依据时排除。必备和优先按引文关键词保守判断，模型分类仍需用户结合原文判断。

未知公司、城市、经验和日期明确展示，不补全。技能描述由模型解释，不属于招聘原文。未加入额外的 AI 前置学习建议，避免混入招聘技能。有效样本不足、企业来源有限和排除页面均有提示。

## 隐私、可靠性与限制

计划与笔记仅保存在当前源的 localStorage，不上传服务端，不自动跨设备同步。导入上限 5 MB／100 份计划／每份 200 项任务。恢复损坏存储前可导出原始值。清除浏览器数据、切换域名或使用无痕窗口会影响计划持久性；定期备份。

检索仅发送岗位与筛选条件，密钥仅在服务端。只调用固定搜索 API 和维护者配置的模型地址，不直接请求浏览器传入的 URL。引用链接只允许公开 HTTPS 格式，React 转义所有招聘文本。

检索有 90 秒服务端超时、客户端取消和超时，以及同实例并发与频率限制。该限流不跨 Worker 实例；扩大用户规模前需配置平台级限流和请求预算。第一版尚无跨请求持久检索缓存。

## 界面与动效

参考 Apple 中国官网首页及 MacBook Pro 产品页的大标题、留白和分段呈现，采用原创的产品功能预览。界面保持黑白配色；首屏分层进场、滚动渐显、导航背景变化、按钮和技能选择反馈均使用原生 CSS 与 IntersectionObserver，无额外动画依赖。视口观察完成后会取消观察；没有逐帧滚动监听，也不接管滚动。系统启用减少动态效果时，CSS 和运行时代码均关闭位移、缩放和渐显隐藏。JavaScript 或视口观察不可用时，正文默认可见。

参考页面：https://www.apple.com.cn/ ，https://www.apple.com.cn/macbook-pro/proled-xdr-display/ 。功能预览明确标注演示内容，不作为真实招聘数据。

鼠标拖尾使用原生 Canvas：白色短荧光线，路径上限 62 CSS 像素，170ms 内淡出。只在鼠标精细指针设备且未启用减少动态效果时生效；停止移动后结束动画帧，离开窗口或切换后台立即清除。画布不拦截任何指针事件。
